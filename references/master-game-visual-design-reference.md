# Master-Level Game Visual Design Reference

Use this reference when upgrading or operating art-related agents at master level.

## Core Rule

Art-related agents may study top commercial and award-recognized games for visual principles, production methods, readability standards, and market quality bars. They must not copy names, logos, characters, UI layouts, icons, economies, exact silhouettes, proprietary assets, or distinctive compositions.

The purpose is to learn why the work succeeds, not to recreate what it looks like.

## Market Learning Signals

Use these signals to identify high-level references:

- Award-recognized visual craft: Game Developers Choice Awards Best Visual Art, BAFTA Artistic Achievement, The Game Awards Best Art Direction, and equivalent craft awards.
- Durable market impact: games whose visual identity remains recognizable after years.
- Production usefulness: games that solve real development problems such as small-screen readability, dense combat clarity, modular UI, fast asset iteration, or strong art direction with limited team size.
- 2D relevance: sprite clarity, animation economy, tile/layer construction, parallax, UI readability, VFX timing, and engine-ready assets.

## Shared Master Skills

- Reference decomposition without copying.
- Art bible construction.
- Visual identity and market differentiation.
- Silhouette, value, and color readability.
- 2D camera/view and target-size awareness.
- Color script and mood progression.
- Shape language systems.
- UI visual state systems.
- Animation timing and action readability.
- Sprite sheet QC and metadata.
- TileMap/layer/y-sort/collision handoff.
- Atlas/import/performance budgeting.
- Originality and anti-copying review.

## Master-Level Review Questions

- Can the game be identified from one screenshot without text or logo?
- Can the player understand role, threat, interactability, and reward at gameplay size?
- Does the visual style support the game's promise and target player?
- Does the scene guide attention without covering gameplay rules?
- Does the UI feel native to this game, not like a generic overlay?
- Are the assets production-ready, with pivots, anchors, collision, layers, animation timing, import rules, and QC previews?
- If a reference disappeared, would this design still stand as original work?

## Forbidden Behaviors

- Copying exact silhouettes, character designs, icons, UI layouts, typography, currencies, or proprietary assets.
- Using a successful game's color palette, layout, or icon set as a skin.
- Treating AI image output as final art direction.
- Ignoring 2D technical requirements because a still image looks good.
- Prioritizing decoration over gameplay readability.
