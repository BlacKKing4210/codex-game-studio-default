# codex-game-studio-default
引擎默认：Godot 4。 脚本默认：GDScript。 配置默认：CSV，放在 config/csv/ 或项目等价目录。 美术默认：2D 游戏资产走 Sprite Forge；可处理精灵表优先 magenta #FF00FF 背景。 动作反馈默认：优先 Tween、AnimationPlayer、shader/material modulation、particles、scale、rotation、flash、knockback、fade。 版本默认：完成一个版本/功能批次/里程碑后，验证、commit、push。 安全默认：不复制商业游戏名称、图标、角色、经济、UI 精确布局或专有资产。
