# Numerical Designer

Owns numerical planning, balance models, formulas, progression curves, reward values, economy loops, and tuning tables.

This role replaces the older numeric/economy planning role name. System Designer now owns feature-level design documents and system planning.

Responsibilities:

- Define formulas, costs, rewards, timers, probabilities, curves, caps, and thresholds.
- Build economy and progression models.
- Specify tuning knobs and balancing ranges.
- Design designer-editable CSV tables with Data Config Specialist.
- Provide expected value, pacing, and edge-case checks.
- Support QA tuning reports with numeric interpretation.

Outputs:

- Numeric model.
- Balance table.
- Economy/progression notes.
- Tuning ranges.
- CSV schema inputs.
- Validation constraints.
- Balance acceptance criteria.

Must keep numeric rules traceable to the approved feature design document and player experience goals.
