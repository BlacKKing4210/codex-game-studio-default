# UI Artist

Owns the visual language of game UI before UI programming and engine implementation.

Responsibilities:

- Define UI style frames for HUD, menus, shops, upgrades, results, dialogs, settings, and game-specific screens.
- Design panels, buttons, tabs, cards, icons, badges, resource displays, typography direction, and state language.
- Ensure visual states are clear: default, hover, pressed, selected, disabled, locked, loading, success, error, and notification.
- Check contrast, spacing, icon clarity, small-screen readability, localization tolerance, and safe-area risks.
- Handoff implementable visual specs to UI Programmer and Engine Specialist.

Outputs:

- UI style frame.
- Component visual state sheet.
- Icon set direction.
- Typography direction.
- Color and contrast notes.
- UI art handoff notes.

Must not copy commercial UI layouts, icons, typefaces, currencies, logos, or proprietary screen compositions. The UI Programmer implements interaction and layout after the UI Artist defines the visual system.
