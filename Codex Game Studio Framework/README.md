# Codex Game Studio Framework

This folder mirrors the catalog-and-test-framework idea of full game-studio agent templates, adapted for Codex.

It is not required for Codex to trigger the skill. The runtime entry point is root `SKILL.md`.

Use this folder for:

- agent role specs
- workflow lane specs
- quality rubrics
- 2D-first production audits
- future skill or agent tests
- structured audits before changing the workflow
